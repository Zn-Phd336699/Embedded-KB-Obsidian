# TC21 电源纹波测量规范

## 现象
示波器测 Buck 输出纹波 200~500mVpp，而数据手册标称几十 mV；换个人测就变小——典型测量方法性虚高，而非电源真差。

## 环境与适用范围
适用毫伏级电源纹波测量（DC-DC/LDO 输出）。元凶是 10:1 无源探头 + 长鳄鱼地线构成的大感应环路。高压隔离测点的差分测量不在此列。

## 取证过程
1. 本底测试：拔下被测板，弹簧地短接探头尖与地，读本底噪声（应 <2~5mVpp），先排除仪器因素。
2. 检查接地方式：长鳄鱼地线 = 大环路，拾取开关节点辐射场与地磁通叠加进读数——虚高的主源。
3. 按 SOP 规范重测（见修复方案）：弹簧地贴测点、AC 耦合、20MHz 带宽限制、最小量程档。
4. 读数方式：无限余辉/直方图统计峰峰值，勿目测单帧；报告中注明带宽与接地设置。
5. 规范测量仍超标才是真问题：此时开全带宽查开关振铃、输出电容 ESR 与功率环路布局。

## 根因
探头尖与长地线围成面积 A 的环路，磁感应电压正比 dΦ/dt ∝ A，开关节点的 di/dt 辐射被直接串入读数，共模地环流再加一笔；环路越大虚高越狠，可达十倍以上。

## 修复方案
```text
毫伏级纹波规范五步：
1. 摘除长地线/夹子，套探头前端弹簧地，贴测点旁地孔或地铜皮
2. 或短双绞+50Ω 馈通 BNC 直焊被测点，示波器输入置 50Ω（注意耐压）
3. 垂直档位打最小档(5~10mV/div)，耦合置 AC
4. 开启 20MHz 带宽限制作为默认读数档；分析振铃时另开全带宽
5. 余辉累积 ≥100 个开关周期后读 Pk-Pk 统计值，
   报告注明：探头型号/接地方式/带宽限制/耦合/量程
若规范测量仍超标 → 加大输出容或换低 ESR、缩短功率环路、必要时加 π 型滤波
```

## 预防措施
- 台架常备弹簧地探头组件，禁止用长地线测毫伏级信号
- 每次纹波测量前先做探头短接本底校验
- 报告模板强制注明接地方式/带宽/耦合/量程四要素
- 关键电源轨 layout 时预留 Signal+GND 成对测试焊盘
- 团队统一「纹波测量 SOP」，新人上岗考核
