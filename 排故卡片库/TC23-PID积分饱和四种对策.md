# TC23 PID 积分饱和四种对策

## 现象
设定值大阶跃（如 25℃→85℃ 温控）后执行器长期 100% 满输出，到达设定后冲过头 8~12℃ 缓慢回落；积分项数值巨大。典型触发：误差长时间同号使积分无界累积。

## 环境与适用范围
适用位置式数字 PID（温控/电机/压力等）；增量式同样存在饱和。纯 P/D 控制不涉及。

## 取证过程
1. 数据回放：按 dt 记录 sp/pv/积分项/输出 u，确认 u 长期贴上限且积分项持续单调增大。
2. 检查实现：PID 库有无任何抗饱和措施；dt 是否来自硬件定时器（dt 抖动放大积分误差）。
3. 阶跃对拍：同一对象分别跑 无抗饱和/钳位/反算/条件积分，记录超调量与调节时间。
4. 参数核查：Ki 偏大 + 执行器限幅严的场景 windup 最猛，先确认限幅值合理性。
5. 按对象特性选对策落地并回归测试（见下表）。

## 根因
积分项对误差持续累积而无界增长；输出饱和期间误差仍同号，等误差反号时必须先「消化」多余积分才能让输出离开饱和区——超调由此而来。

## 修复方案
四策对比：

| 对策 | 做法 | 优点 | 代价 |
|------|------|------|------|
| 积分钳位 | 积分限幅在 [imin, imax] | 零成本兜底 | 限幅值靠经验，仍可能超调 |
| 反算回灌 | 饱和时按 Kt*(usat-u) 回灌积分 | 退出平滑，工程首选 | 多一个参数 Kt≈1/Tt |
| 条件积分 | 误差大或已饱和时冻结积分 | 不加参数 | 大误差期间只剩 PD，爬升慢 |
| 积分分离 | abs(e)>阈值切除 I，进带内恢复 | 响应快 | 切换不当引起输出抖动 |

```c
float pid_step(PID *p, float sp, float pv)
{
    float e = sp - pv;
    p->i += p->ki * e * p->dt;
    if (fabsf(e) > p->e_gate)            /* 条件积分：大误差不积累 */
        p->i -= p->ki * e * p->dt;

    float u    = p->kp * e + p->i + p->kd * p->dterm;
    float usat = clampf(u, p->umin, p->umax);
    p->i += p->kt * (usat - u) * p->dt;  /* 反算抗饱和：饱和时回灌 */
    return usat;
}
```

## 预防措施
- 任何积分器默认内置钳位，作为库级底线
- 输出限幅与饱和检测封装进 PID 模块，业务层无感
- 阶跃响应验收写明超调百分比与调节时间指标
- 选型口诀：慢对象用条件积分，快对象用反算
- dt 由硬件定时器提供，禁止主循环软计时
