# 第53章 RTOS 综合实战：三轴云台控制器

## 🎯 学习目标

## 53.1 系统规格与任务表

| 需求 | 指标 | 实现载体 |
|------|------|----------|
| 电流环 | 10kHz 固定周期，jitter<2µs | TIM 触发 ADC→DMA→FOC 计算（最高优） |
| 速度环 | 1kHz | 电流环同任务内分频执行 |
| 位置环+姿态解算 | 500Hz，Mahony/Madgwick | att_task 中优先级 |
| 遥控通信 | CAN/SBUS 接收解析 | comm_task 低优先级+队列 |
| 参数管理/遥测 | 10Hz 上报 | telem_task 最低优先级 |

## 53.2 关键代码：双速率单任务 FOC 架构
```c
/* 双速率单任务模式：避免高频切换开销，且两环数据天然同源一致 */
void foc_task(void *arg) {                 /* prio 7 最高业务优先级 */
    TickType_t last = xTaskGetTickCount();
    for (;;) {
        xSemaphoreTake(adc_done_sem, portMAX_DELAY); /* TIM触发ADC完成唤醒 */
        foc_current_loop();                          /* 10kHz */
        if (++divider >= 10) { divider = 0; foc_speed_loop(); } /* 1kHz */
    }
}
/* 实时预算：电流环 C≈28µs(F407 FPU实测) << T=100µs ✓
   最坏链分析：ISR(2µs)+foc(28µs)+临界区(3µs) = 33µs < 100µs×70%红线 */
```

## 53.3 实测数据表：实时预算与验收门

| 项目 | 数值 | 说明 |
|------|------|------|
| 电流环周期 T | 100µs（10kHz） | TIM 触发 ADC→DMA 链 |
| foc_current_loop 耗时 C | ≈28µs | F407 FPU 实测 |
| 最坏链 ISR+foc+临界区 | 33µs | < T×70% 设计红线 ✓ |
| jitter 验收门（速度环 1kHz 为同任务 ÷10 分频） | P99<2µs | M1 里程碑门槛 |
| 阶跃超调 / 静态漂移 | <15% / <1° | M2 / M3 里程碑门槛 |

## 53.4 故障注入测试集五项
1. **jitter 注入**：人为在高优任务插入随机忙等，验证控制环抖动上限与保护策略；
2. **传感器失效**：编码器线断→角度外推+安全停机流程触发；IMU 卡死（数据不变检测）；
3. **过流冲击**：软件模拟堵转，验证三级保护（软件限流→PWM 封锁→断使能）；
4. **看门狗矩阵**：分别冻结每个任务，观察 WDG 分级复位行为是否符合设计；
5. **长跑老化**：8 小时连续运转，统计电流环 jitter 分布 P99/P999 与温漂曲线。

## 53.5 保护三级设计与看门狗矩阵

| 级别 | 动作 | 触发条件 |
|------|------|----------|
| L1 软件限流 | 输出限幅/降转矩 | 电流越限但未持续 |
| L2 PWM 封锁 | 立即封波输出 | 堵转过流确认 |
| L3 断使能 | 切断驱动使能+安全停机 | L2 无效或传感器失效 |

## 53.6 参数调试技巧
| 症状 | 测量手段 | 调什么 | 判据 |
|------|----------|--------|------|
| 抖动随温度恶化 | 上电校零+关管采底噪自校 | 换低温漂采样电阻/周期校准 | P999 抖动全程稳定 |
| IMU 姿态抽搐 | 示波器查 SCK 质量 | 缓冲 aligned(32)+CRC+3σ 离群剔除 | 静止姿态波动收敛 |
| 速度环偶发延迟/阶跃超调大 | Tracealyzer 泳道（见 [[ch51a-可视化追踪Tracealyzer-SystemView]]）+ 阶跃响应录制 | 遥测任务降级限频；PI 整定（[[chfd-A4-PID工程化全集抗饱和自整定]]） | 泳道干扰源消失；超调 <15% |

## 53.7 排故速查表
| 现象 | 根因候选 | 定位路径 |
|------|----------|----------|
| 电流环抖动温升后恶化 | 采样电阻温漂+偏置漂移 | 上电校零存参；运行中「关管采底噪」自校 |
| IMU 数据偶发跳变 | SPI 干扰/DMA 缓冲未对齐 | 查 SCK 波形；aligned(32)+CRC 校验 |
| 高优任务互抢使速度环延迟 | 实时预算表失守 | 回 [[ch45-实时性理论与调度算法]] 预算表；遥测降级限频 |
| 冻结某任务整机不复位 | WDG 分级未覆盖该任务 | 对照看门狗矩阵补喂狗点 |

| 物料 | 规格 | 参考价 |

| 主控 | F407（探索者）或 H743 | - |
| 云台电机×3 | 2205 无刷 + FOC 必要极对数 | ¥60/个 |
| 驱动 | 三合一无刷驱动板(SVPWM+采样电阻) | ¥90 |
| IMU | ICM-42688 或 MPU6500(SPI) | ¥25 |
| 编码器 | AS5048A 磁编码(SPI/PWM) | ¥30/个 |
| 结构件 | 3D 打印三轴架+轴承 | ¥40 |

1. 电流环任务保持最高业务优先级，任何新任务入表前先做实时预算复核；
2. TIM→ADC→DMA 触发链固定后锁定时钟树配置，防止中间件改动引入抖动；
3. 参数保存/Flash 写放最低优后台任务，避开控制环活跃窗口；
4. 出厂前五项故障注入必须全过（对应 M5 门 S1~S4）；8h 老化的温升与 jitter 分布曲线归档为产品基线数据。

```text
git 分步路线：
M1 电流环: ADC 注入组+FOC 开环旋转验证      → 门：jitter P99<2µs
M2 速度环: 编码器读取+PI 整定               → 门：阶跃超调<15%
M3 姿态解算: Mahony 滤波+静态漂移标定       → 门：静止 1° 内
```

> [!warning]- ❓ FAQ
> **Q1：电流环抖动随温度恶化怎么办？** 采样电阻温漂+偏置漂移所致。上电校零存参数、运行中周期性「关管采底噪」自校；硬件侧选低温漂电阻。
> **Q2：IMU 数据偶发跳变导致姿态抽搐？** SPI 干扰或 DMA 缓冲未对齐。示波器查 SCK 质量；缓冲 aligned(32)+CRC 校验；软件加 3σ 离群剔除。
> **Q3：两个高优任务互抢 CPU 使速度环延迟？** 回到 ch45 预算表：把遥测类任务降级并限频；用 Tracealyzer 泳道确认干扰源（见 ch51a）。

> [!question] 📝 思考题
> 1. 为什么把速度环放进电流环同任务而不是独立任务？从切换开销与数据一致性两方面论证。
> 2. 设计 IMU 与编码器融合的姿态观测器容错逻辑（置信度加权）。
> 3. 给出本项目迁移到 STM32H7（480MHz）的性能提升预估清单与瓶颈新变化。
