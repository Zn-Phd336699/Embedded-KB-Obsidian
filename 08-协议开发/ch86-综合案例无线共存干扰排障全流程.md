# 第86章 综合案例：无线共存干扰排障全流程

> [!info] 导航

## 🎯 学习目标
- [ ] 掌握 2.4G 五类共存机理（同频/邻频/谐波/阻塞/电源耦合）并对号入座
- [ ] 实施「频谱仪+空口抓包+日志」三线并行取证，量化干扰深度
- [ ] 按性价比输出软件/驱动/硬件/结构四层整改清单并完成闭环验证

## 86.1 案例背景与症状矩阵

产品：智能网关 = WiFi(AP 配网)+BLE(传感器)+LoRa(远传)+Cat.1(上云)。症状矩阵：WiFi 下载时 BLE 掉线率 40%；Cat.1 发射瞬间 WiFi 吞吐骤降；LoRa 上报后偶发 BLE 广播丢失。
规律：全部问题都在「另一个射频同时工作」时出现——共存问题确诊。取证结论示例：Cat.1 天线距 WiFi 天线仅 15mm 且无隔离带 → LTE B1/B3 二次谐波落入 2.4G → WiFi 灵敏度恶化 20dB。

## 86.2 三线取证法

1. **频谱仪线**([[ch20-频谱仪与射频排障]])：TinySA 监视 2.4G，触发 Cat.1 发射观察信道底噪抬升幅度——量化「阻塞深度」；
2. **空口抓包线**：ESP32 sniffer/monitor 模式记录 BLE 广播与 WiFi 重传的时间轴重叠；
3. **日志线**：设备侧统一毫秒级时间戳（同源时钟，[[ch14-日志系统设计RTT与远程回传]]），把「发送事件-失败事件」对齐成时间轴。

## 86.3 干扰机理速查

| 机理 | 特征 | 对策方向 |
|------|------|----------|
| 同频冲突 | 双方都在 2.4G 信道 X | 信道规划+时分协调(PTA) |
| 邻频泄漏 | 发射掩码外滚降进入他带 | 降功率/滤波器 |
| 谐波/杂散 | Sub-G/LTE 谐波落 2.4G | 源头滤波+天线隔离 |
| 接收阻塞 | 强信号压坏 LNA 增益点 | 空间隔离/前端 SAW |
| 电源耦合 | PA 突发电流拉垮 VCO | 独立 LDO/大电容就近 |

## 86.4 整改清单模板（按性价比排序）

1. **软件零成本层**：时分调度表——LoRa/Cat.1 发射窗口避开 BLE 连接事件；WiFi 限功率 13dBm；BLE 连接间隔放宽到 50ms 降低占空比；
2. **驱动参数层**：开启芯片共存接口 PTA（SoC 支持时）；WiFi 与 BLE 同一 combo 芯片时启用内建仲裁；
3. **硬件层**：天线间距 ≥λ/4（2.4G≈31mm）且正交极化；敏感接收前端加 SAW/BPF；PA 供电独立 LC 滤波；屏蔽罩补齐；
4. **结构层**：金属件远离天线净空区（≥10mm）；馈线走线远离时钟线（EMI 清单联动 ch20）。

软件层时分协调能解决一半问题，但别用它掩盖硬件缺陷。

## 86.5 PTA 分组流量仲裁原理

PTA(Packet Traffic Arbitration)=两射频芯片间的「交通信号灯」，思想源头 IEEE 802.15.2 WPAN 共存建议：

```text
· 请求线： 射频 A 要发射时拉 REQUEST + 优先级位
· 判决：   共存控制器按优先级/正在进行的包决定 GRANT
· 状态线： 告知对方「我在收高优先级包，勿扰」
单芯片 combo 的软件对应物： ESP32 coexist 组件自动仲裁且参数可调：
  wifi 静默期保护 BLE 连接事件 / BLE 让路给 WiFi TXOP
没有硬件共存接口的板子 → 只能纯软件时分：全局调度器把 LoRa/Cat.1 发射窗口避开 BLE conn interval(86.4 第①层)
```

## 86.6 共存参数配置实例库

| 平台/组合 | 关键配置项 | 推荐值与说明 |
|-----------|------------|--------------|
| ESP32 WiFi+BLE | CONFIG_ESP_COEX_ENABLED / 共存优先级表 | 开启；BLE 连接事件优先(权重按业务调) |
| WiFi+LoRa 分立芯片 | 软件时分调度器：LoRa TX 前请求「WiFi 静默窗」暂停大流量 200ms | 业务层令牌桶限速窗口即可实现 |
| Cat.1+2.4G WiFi | AT+QBandSel 锁 LTE 频段避开谐波重叠档位；同模组 BLE conn interval ≥30ms 留空口时间片 | 锁频段是最便宜的「滤波器」 |

## 86.7 实测数据表：整改前后共存指标对比（真实数据脱敏）

| 指标 | 整改前 | 整改后(天线隔离+时分调度) |
|------|--------|---------------------------|
| BLE 掉线率(24h) | 38% | 0.2% |
| Cat.1 发射期 WiFi 吞吐跌幅 | -72% | -11% |
| LoRa 上报成功率 | 91% | 99.6% |
| 整机待机功耗 | +18%(重传开销) | 回落基线 |

投入：改板一次+两周软件；回报：从「不可用」到「可量产」。验证闭环目标：满负荷共存 BLE 掉线率 <0.5%/24h；Cat.1 发射中 WiFi 吞吐跌幅 <15%；三射频并发误码回到单独基线 +3dB 内；金属柜极端位置回归无新增故障模式。

## 86.8 排障 SOP：现象分级→频谱取证→定位→整改→回归

1. **现象分级**：是否只在多射频并发时出现？偶发还是必现？先按共存立案再怀疑软件；
2. **频谱取证**：TinySA MaxHold 截图（发现间歇性干扰第一神器），触发发射记录底噪抬升 dB 数；
3. **定位**：三线时间轴对齐，锁定「谁发射、害了谁、什么机理」；
4. **整改**：按 86.4 性价比顺序实施，逐项复测留痕；
5. **回归**：三项核心指标前后对照+极端环境全集回归，归档进「干扰指纹库」（现象-根因-对策）复用。

## 86.9 现场勘测七步法（售前/售后通用 SOP）

```text
《无线环境勘测记录单》七步法：
□1 平面图标注设备位置与最近干扰源(电梯/微波炉/配电房)
□2 TinySA 全频段扫描三点位(MaxHold 截图)
□3 目标信道底噪与占用度记录(对比时段×2)
□4 现有同频网络盘点(SSID/信道/信号)
□5 设备试装点位通信质量(RSSI/延迟/丢包 各测 5 分钟)
□6 天线方案预判(增益/方向/走线长度)
□7 结论与风险声明(签字) —— 把「应该没问题」变成可追溯的工程承诺
```

## 86.10 第三类问题：电源时序串扰

- **现象指纹**：PA 启动瞬间另一颗芯片 I2C 读数毛刺或复位——不是空口干扰而是**电源耦合**（示波器查供电轨定位）；
- **对策梯度**：就近储能电容 → LC π 滤波独立供电域 → PA 供电压摆控制(软件限制发射占空比)；
- **设计期预防**：原理图评审必查「PA 电源是否与敏感模拟共轨」——一条检查项省一轮改板。

## 86.11 排故速查表

| 现象 | 根因候选 | 定位路径 |
|------|----------|----------|
| WiFi 下载时 BLE 频繁掉线 | 同频冲突/接收阻塞 | 信道规划+PTA 仲裁；BLE conn interval 放宽 |
| LTE 发射时 WiFi 吞吐骤降 | LTE 谐波落 2.4G/接收阻塞 | TinySA 看底噪抬升幅度；锁频段+天线隔离 |
| LoRa 发射后 BLE 广播丢失 | Sub-G 谐波杂散/电源耦合 | 频谱看杂散落点；示波器抓 PA 启动瞬间供电轨跌落 |

## 86.12 部署注意事项
1. 多射频产品的天线布局在原理图阶段就要定——改板一次六位数；任何「偶发」无线问题先怀疑共存再怀疑软件；
2. 时间戳统一（毫秒级、同源时钟）是三线取证的生命线；认证前预扫描能省下 80% 整改往返；
3. 功率/信道留可配置余量应对 DFS/LBT 法规义务；每次案例归档「现象-根因-对策」入干扰指纹库；
4. 与射频同事沟通用 dB 和频谱图说话；留出 20% 时间做「无仪器回归」——现场环境才是最终考场。

> [!example]- 🧪 动手实验 L86-1：复现 WiFi↔BLE 冲突并出具整改报告（120 分钟）
> **步骤**：① ESP32 同时跑 STA 大下载+BLE 从机连接，nRF Connect 记录掉线间隔，关下载做对照组；② 开 coexist 参数并放宽 conn interval 复测，sniffer 对比 BLE 收发窗口被挤占形态；③ 任选双射频真机按三线取证采基线，实施 86.4 清单至少两项，复测三项核心指标形成前后对照；④ 按 86.9 模板输出报告。**验收**：四组数据+两张空口截图+一份「外行能看懂结论、内行能复核数据」的报告。

## 86.13 进阶话题
- UWB 脉冲干扰特性不同于连续波，高精度测距产品需专项评估；DFS/LBT 法规义务在认证中占比逐年上升，设计期留可配置功率/信道；
- 参考实现：Linux btcoex 驱动注释(ath9k)；Espressif《Wi-Fi/Bluetooth coexistence》文档；IEEE 802.15.2 规范。

> [!warning]- ❓ FAQ
> **Q1：软件时分协调能否根治共存问题？** 只能缓解约一半；若根因是谐波/阻塞等硬件缺陷，必须天线隔离+滤波整改，否则换环境即复发。
> **Q2：两天线怎么摆才够隔离？** 间距 ≥λ/4（2.4G≈31mm）起步并正交极化，敏感接收前端加 SAW；用底噪抬升 dB 数量化验证效果。
