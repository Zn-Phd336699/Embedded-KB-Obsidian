# 第18章 示波器实战：从探头补偿到电源纹波测量

> [!info] 导航
> ⏱ 40min | ★★★☆☆ | 前置 [[ch17-Wireshark-tcpdump抓包分析]] | → [[ch19-逻辑分析仪与sigrok]]

软件工程师也要会摸示波器（Oscilloscope）：串口波形解码、I2C 时序验证、电源纹波三个场景覆盖 90% 用途。本章以 DS1054Z 为参照机型。

## 🎯 学习目标
- [ ] 完成探头补偿、采样率/存储深度规划、触发系统设置三项基本功
- [ ] 用 Decode 功能解码 UART/I2C 波形并对照协议时序定位错误
- [ ] 按「接地弹簧 + AC 耦合 + 20MHz 带宽限制」铁律测量纹波与启动浪涌，并用 FFT/脉宽触发抓偶发异常

## 18.1 开机三件事
1. **探头补偿**：钩住示波器自带 Comp 方波（DS1054Z 在右下角），调探头微调电容直到方波平顶——欠补偿圆角、过补偿尖峰。换探头/换通道都要重做。
2. **带宽与采样**：奈奎斯特要求采样率 ≥2× 信号频率，实际取 4~10 倍；DS1054Z 默认 1GSa/s 单通道足够。存储深度固定时提高采样率会缩短记录时长——测低频长过程要主动降时基。
3. **触发**：默认 Auto（自由跑）只用来找信号；稳定测量切 Normal 并设边沿触发电平；抓偶发毛刺用 Pulse Width（如 <100ns 正脉冲）；按协议内容触发选 Serial 解码触发。

## 18.2 场景一：UART 波形验证
```text
接线：探头地夹接GND，钩针接TX线（115200bps, 8N1）
设置：时基 200µs/div；垂直 1V/div；Decode→UART→115200→8bit 无校验
判读：
  空闲电平=3.3V高；起始位=拉低1bit(8.68µs)
  LSB先行：0x55=01010101b → 交替方波（训练信号首选）
  波特率误差容忍≈±2%（两端都错雪上加霜）——光标量一位宽度比对理论值
异常指纹：
  电平只到2V左右 → 上拉缺失/驱动弱/线太长分布电容大
  边沿爬升缓慢   → 加线端串联22~33Ω或降低波特率（[[ch28-串口工程化IDLE-DMA-RS485]]对策）
  偶发位宽抖动   → 两端时钟源不准（内部RC vs 晶振）
```

## 18.3 场景二：I2C 时序体检
| 检查项 | 合格标准（400kHz 模式典型值） | 不合格后果 |
|--------|------------------------------|------------|
| SCL 高电平时间 | ≥0.6µs | 过短=上拉过强或驱动不足导致从机跟不上 |
| 上升沿时间 | <300ns（由 Rp×Cb 决定） | 过长→数据建立失败，随机 NACK |
| 总线空闲电平 | 稳定 VDD | 半高不落底=有器件拉死总线（见 [[ch76-I2C协议与排障时钟拉伸总线锁死多主机]]） |
| Clock Stretching | 从机可在 SCL 低保持 | 主机不支持 stretch 却遇到会读错位 |

操作要点：CH1→SCL、CH2→SDA 双探头同时挂线，Decode 选 I2C 并填地址方向；用 **Zoom 分屏**放大到 NACK 附近逐位核对。

```text
标准 I2C 体检 SOP：
① 接线：CH1→SCL CH2→SDA，接地弹簧就近接板 GND
② 设置：500kSa/s 起步（400kHz 总线的 1250 倍过采样）；Decode=I2C
③ 判读清单：
   □ 高电平到 VDD(3.3V)？低于 3V=上拉不足或驱动弱
   □ 上升沿 tr：光标量 10%~90%，>300ns@FM 需减上拉
   □ 低电平接近 0V？>0.4V=灌电流超标或地弹
   □ SCL 有无非主机产生的低保持？→ clock stretching 存在性
   □ ACK 位干净拉低？高位 NACK 即刻查地址/供电
④ 截图归档实验笔记（含时基/垂直档位元数据）
```

## 18.4 场景三：电源完整性两板斧
```text
纹波测量（DC-DC输出）铁律：接地弹簧 + AC耦合 + 带宽限制BW Limit=20MHz
  ① 探头拨到1X并用接地弹簧替代长地夹（长地环拾取磁辐射=假纹波）
  ② AC耦合，20MHz BWL 开启（滤除高频噪声聚焦开关纹波）
  ③ 量峰峰值：典型合格值 LDO<5mV，Buck<50mV（视规格）
  ④ 纹波超标看频谱：基波=开关频率→输出电容ESR问题；
     高频毛刺→布局回路大，加RC snubber或改善铺地

浪涌/启动电流：
  电流探头，或串小阻值采样电阻(0.05Ω)+差分探头
  关注：电容充电尖峰是否触发限流保护；WiFi发射瞬间电源跌落深度
       （ESP32 TX burst ~500mA）——这是「WiFi一开MCU就复位」的标准诊断法！
```

## 18.5 触发系统：示波器的灵魂
| 触发类型 | 用途 | 典型设置场景 |
|----------|------|--------------|
| Edge 边沿 | 稳定显示周期信号 | Normal+合适电平，别用 Auto 看偶发 |
| Pulse Width | 抓窄毛刺/超宽异常 | <50ns 正脉冲 → 定位中断抖动毛刺 |
| Serial(UART/I2C) | 按协议内容触发 | 等特定地址/字节出现再采——总线排障利器 |
| Runt/Window | 幅度异常穿越 | 信号跌入窗口即触发——电源跌落检测 |
| 分段存储 Sequence | 稀疏事件长记录 | 只在触发段占用内存，等效时长 ×10+ |

## 18.6 参数调试技巧
| 症状 | 测量手段 | 调什么 | 判据 |
|------|----------|--------|------|
| 波形全是噪声毛刺 | 探头悬空空测对比本底 | 换接地弹簧、缩短地回路 | 毛刺消失=原为假纹波 |
| 测 PWM 占空比不准 | 核对默认 50% 阈值 | Measurement 里自定义 High/Low 阈值 | 与实际驱动电平一致 |
| 抓不到偶发异常 | 审查触发方式 | Normal+脉宽触发；加记录深度；分段采集 | 连续运行能命中事件 |
| 幅值比万用表差很多 | 核对探头 10X\|1X 倍率 | 统一倍率并重新补偿校准 | 两表读数一致 |

## 18.7 实测参考数据表
| 场景 | 指标 A | 指标 B |
|------|--------|--------|
| LDO 输出纹波 | <5mVpp（典型值） | AC 耦合 + 20MHz BWL 下测量 |
| Buck 输出纹波 | <50mVpp（典型值，视规格） | 超标看频谱成分定位 ESR/布局 |
| 400kHz I2C 上升沿 | <300ns | 由 Rp×Cb 决定 |
| ESP32 WiFi TX 浪涌 | ~500mA burst（典型值） | 监测电源跌落是否复位 MCU |
| DS1054Z 记录窗口 | 24M 点 @1GSa/s = 24ms | 降到 1MSa/s 可抓秒级上电序列 |

## 18.8 排故速查表
| 现象 | 根因候选 | 定位路径 |
|------|----------|----------|
| 波形全是噪声毛刺 | 长地夹形成环路天线 | 换接地弹簧；空测对比本底噪声 |
| 幅值比万用表差很多 | 探头倍率与示波器设置不一致 | 统一 10X/1X；重新补偿校准 |
| 抓不到偶发异常 | Auto 触发乱跳错过 | Normal+脉宽触发；加长记录深度；分段采集 |
| 测 PWM 占空比不准 | 默认 50% 阈值与驱动电平不符 | 自定义 High/Low 阈值 |

## 18.9 部署注意事项
1. 每次换探头/换通道必做补偿，笔记里留方波截图作为计量证据。
2. 纹波测量铁律三件套不可省略任何一项，否则看到的是「空间电磁环境」而不是被测电源。
3. 先算需要的时间窗再定采样率——存储深度与采样率是跷跷板。
4. 波形导出 CSV 而非只留截图，便于 Python 重绘多次改版对比，把仪器截图升级为可计算数据。
5. 注意探头负载效应：10X 探头约 15pF 在高速线上就是容性负载，测 100MHz 时钟会自己把边沿变缓。

> [!example]- 🧪 动手实验 L18-1：双任务实测（45 分钟）
> **步骤**：A 部分-串口解码：① 探头挂 TX，开启 115200 解码；② 发送 `0x55` 训练字核对 LSB-first 位序；③ 故意设错波特率一档观察 framing error 表现。B 部分-电源纹波：① 找板上 DC-DC 输出，接地弹簧+AC 耦合+20MHz BWL；② 测峰峰值并用 FFT 看主频成分；③ 输出并联一颗 10µF 对比改善。
> **验收**：两组截图+数据入笔记，并能回答「为什么 B 部分不用长地夹」。

## 18.10 进阶话题
- **单次捕获 Single + Normal 触发**：抓一次性事件（上电时序、按键去抖后的干净边沿）。
- **FFT 功能**：时域杂讯转频域看干扰成分——预算版频谱仪，正式工具见 [[ch20-频谱仪与射频排障]]；谐波族间隔=开关频率。
- **XY 模式**：画 I-V 曲线排查二极管/电容特性（维修向）。
- **差分测量应急**：两单端通道 Math 相减可测 RS485 A-B，但 CMRR 有限；正经活用差分探头或电流钳。

> [!warning]- ❓ FAQ
> **Q1：为什么测纹波不能用长地夹？** 长鳄鱼地线等效电感约 100nH/cm 且构成环路天线，拾取空间磁场叠加出「假纹波」，必须换接地弹簧。
> **Q2：DS1054Z 能解锁 100MHz 吗？** 官方选项码社区公开，输入激活即可解锁 100MHz/500MSa——合规性自酌，量产计量场景慎用。

> [!question] 📝 思考题
> 1. 推导探头 1X 与 10X 模式下输入阻抗/电容的差异及对被测电路的影响。
> 2. 为「ESP32 WiFi 发射瞬间电源跌落」设计完整测量方案并给出整改清单。
> 3. 用 FFT 找出一块板子上 1.2GHz 开关噪声的来源（提示：谐波族间隔=开关频率）。
