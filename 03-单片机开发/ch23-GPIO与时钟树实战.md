## 23.1 四种输出模式决策表

| 模式 | 电气特征 | 典型场景 |
|------|----------|----------|
| 推挽 PP | 双管驱动，高低都硬 | LED、普通数字信号（默认选择） |
| 开漏 OD | 只能拉低，高靠上拉 | I2C 总线、多设备线与、电平转换（配合上拉到别的域） |
| 复用推挽 AF-PP | 信号源换成片上外设 | UART TX、SPI SCK 等 |
| 复用开漏 AF-OD | 外设+开漏 | I2C 由硬件外设接管时 |

> [!tip] 开漏的三大妙用
> ① **线与仲裁**：多个开漏输出并联天然实现「任一拉低即低」；② **电平桥接**：3.3V 开漏 + 5V 上拉直驱 5V 器件输入；③ **双向总线**：I2C 的 SDA 一根线既出又入。代价是上升沿由 RC 决定——上拉越强边沿越陡但灌电流越大，典型取值 2.2k~10kΩ 按 ch18 的边沿测量闭环调整。

## 23.2 原理深挖：BSRR 原子性的汇编证据

```asm
; ODR 读改写(非原子) 编译产物：
    ldr  r1, =0x40020014
    ldr  r2, [r1]        ; ① 读 —— 若此处被打断且 ISR 改了同寄存器…
    orr  r2, r2, #0x200  ; ② 改
    str  r2, [r1]        ; ③ 写回 —— 覆盖 ISR 的修改！竞态窗口 3 条指令
; BSRR 单指令写(原子)：
    movw r2, #0x0200     ; 置位/复位编码在同一写动作里完成
    ldr  r1, =0x40020018 ; BSRR 地址
    str  r2, [r1]        ; 一条 str，硬件保证无中间态
; 结论： 多位同时操作或 ISR 共享引脚场景，BSRR 是唯一正确选择
```

## 23.3 关键代码：寄存器级点灯（知其所以然）

```c
/* LED0=PF9 探索者原理图：低电平点亮 */
RCC->AHB1ENR   |= RCC_AHB1ENR_GPIOFEN;   /* ① 先开时钟！忘开=写无效 */
GPIOF->MODER   &= ~(3u << (9 * 2));      /* ② 清模式位 */
GPIOF->MODER   |=  (1u << (9 * 2));      /*    01=通用输出 */
GPIOF->OTYPER  &= ~(1u << 9);            /* ③ 0=推挽 */
GPIOF->OSPEEDR |=  (2u << (9 * 2));      /* ④ 高速档(EMI 与边沿权衡) */
GPIOF->PUPDR   &= ~(3u << (9 * 2));      /* ⑤ 输出模式无需上下拉 */
GPIOF->BSRR     =  (1u << 9);            /* ⑥ BSRR 原子置位 → 灭灯 */
GPIOF->BSRR     =  (1u << (9 + 16));     /*    BR 区复位 → 亮灯，单写原子 */
/* 按键 KEY0=PE4(按下接地)：配 01 上拉输入，!(IDR & BIT(4)) 为真即按下 */
```

## 23.4 去抖时间戳法与按键状态机

机械按键抖动 5~20ms。三种去抖对比：①阻塞 delay(20ms) 二次确认——仅教学用，禁用于实时系统；②SysTick **时间戳法**：记录上次变化时刻，间隔 >20ms 才认定有效——★推荐；③移位滤波：连续 N 次采样一致才更新——抗毛刺更强。工程落位：Bsp/ 下 bsp_led.h/.c（init/on/off/toggle 四件套）与 bsp_key.h/.c（扫描式按键）。

```text
/* bsp_key 核心扫描（放 1ms tick 里调用），四态机零阻塞： */
typedef enum { K_IDLE, K_DEBOUNCE, K_PRESSED, K_REPEAT } key_st_t;
每 tick 采样 → 与上次不同则回 DEBOUNCE 计数 20ms；
稳定按下 → 发 KEY_DOWN 事件入队列(ch07)；持续 >800ms 发 LONG_PRESS；
之后每 200ms 连发 REPEAT —— 天然抗抖、支持组合键扩展。
```

## 23.5 复用映射与调试口保护

AF 编号写入 `AFR[pin/8]` 的 `(pin%8)*4` 位段（0~15），具体编号查数据手册 Alternate 表，例：PA9=USART1_TX 是 AF7。
高危提醒：PB3/PB4/PA13/PA14/PA15 默认是 JTAG/SWD 引脚，占用前必须先关调试口映射（SWJ_CFG），否则调试器失联救砖。最常用组合 **SWJ_CFG=010**：释放 PB3/PB4/PA15、保留 SWD。

## 23.6 功耗视角看 GPIO（钉电平清单）

1. 未用引脚配**模拟输入**（施密特触发器关断）或输出固定电平，切忌浮空——悬空 CMOS 输入在线性区反复翻转，实测电源电流可翻倍且易受扰
2. 输出电平与外围匹配：驱动上拉负载时，输出高比输出低省电
3. 进 Stop 前：把悬空的 MOS 栅极、LED 驱动脚全部钉死到确定电平
4. 测量手段联动 [[ch29-低功耗设计]]：电流表 µA 档 + 逐组 MODER 扫描 + 分段断开，找「漏电 GPIO」

## 23.7 实测数据表：输出模式对边沿的影响（PA5@3.3V，50pF 负载）

| 配置 | 上升沿 10-90% | 下降沿 | 备注 |
|------|---------------|--------|------|
| 推挽 High speed | ~4ns | ~4ns | EMI 关注对象 |
| 推挽 Low speed | ~25ns | ~25ns | LED 类足够且辐射最小 |
| 开漏+10kΩ 上拉 | ~500ns(RC) | ~4ns | 不对称！I2C 波形成因 |
| 开漏+2.2kΩ 上拉 | ~110ns | ~4ns | 灌电流 1.5mA@低电平 |

## 23.8 参数调试技巧

| 症状 | 测量手段 | 调什么 | 判据 |
|------|----------|--------|------|
| I2C 波形顶不到高 | 示波器测上升沿并换算 τ=R×C | 减小上拉电阻（10k→4.7k→2.2k） | 上升时间满足总线速率规格 |
| 辐射超标 | 近场探头/示波器看边沿 | OSPEEDR 降到 Low speed | 边沿 ≥25ns 且功能不受限 |
| 怀疑复用冲突 | 回读 AFRH/AFRL 与 MODER | 与数据手册 AF 表比对预期值 | 两分钟内定位配置漂移 |

## 23.9 排故速查表

| 现象 | 根因候选 | 定位路径 |
|------|----------|----------|
| 寄存器写 GPIO 无反应 | RCC 时钟没开/引脚被 JTAG 占用 | 回读 AHB1ENR 与 MODER 验证写入生效 |
| I2C 总线拉不高 | 误配成推挽抢总线/上拉缺失 | 万用表量空闲电平；改 OD+上拉 |
| 按键一次触发多次 | 未去抖/中断里直接处理 | 时间戳法去抖；中断只置标志，处理放任务 |
| 低功耗下电流超标 | 浮空引脚振荡/调试口未释放 | 逐组 MODER 扫描；µA 表分段断开定位 |

## 23.10 部署注意事项

1. 5V 兼容甄别以数据手册 Pin Definition 表的 FT 标记为准，「听说可以」会烧片子
2. 未用脚一律钉死：模拟输入或固定电平，量产固件加 MODER 全量自检
3. 占用 PB3/PB4/PA13/PA14/PA15 前先释放 SWJ_CFG，保留一条调试退路
4. 位带单 bit 寻址是 M3 专属技巧，M4 工程统一改用 BSRR
5. 中断共享或多任务共用的引脚状态翻转，禁止 ODR 读改写，只走 BSRR

## 23.11 进阶话题

- 悬空自激振荡机理：CMOS 输入工作在线性区反复翻转，电源电流翻倍——未用脚必须钉死的物理根源；模拟模式 MODER=11 关断施密特触发器，也是最低功耗的闲置姿态
- 复用冲突排查命令化：读 AFRH/AFRL+MODER 回显比对预期值，配置漂移两分钟现形
- 开源范本：libopencm3 的 gpio 模块是寄存器级 API 极简对照物；QMK 键盘矩阵扫描是去抖与组合键工程化巅峰

> [!warning]- ❓ FAQ
> **Q1：BSRR 为什么能做到原子而 ODR 读改写不能？** BSRR 是只写寄存器：置位区写 1 置高、复位区写 1 置低，一次写动作硬件保证无中间态；ODR 则要「读→改→写」三条指令，中间被打断就会覆盖他人的修改。
> **Q2：为什么推荐时间戳去抖而不是延时消抖？** 阻塞式 delay 在实时系统里冻结调度；时间戳法只比较时刻差，零阻塞且可与状态机无缝结合。

> [!question] 📝 思考题

> 2. 设计一个「零外部器件」的按键长按/短按/连击识别状态机。
