## 25.1 三类定时器速览（F407）
STM32 十几个定时器本质只有三种：基本型数拍子、通用型会 PWM 会捕获、高级型能控电机。

| 类型 | 实例 | 总线时钟 | 能力 |
|------|------|----------|------|
| 基本 | TIM6/7 | APB1 42M→84M | 纯时基 + DAC 触发 |
| 通用 | TIM2~5(32位) / TIM9~14(16位) | 84M / 168M | 时基+PWM+捕获+编码器(TIM2~5) |
| 高级 | TIM1/8 | APB2 168M | 互补输出+死区+刹车+重复计数器 |

注意 APB 预分频 ≠1 时定时器时钟翻倍（×2 规则，见时钟树章）——「PWM 频率差一倍」故障头号来源。

## 25.2 时基与 PWM 计算公式（背下来）
```c
/* 溢出周期 = (PSC+1)*(ARR+1)/Tclk */
/* 例：84MHz, PSC=83, ARR=999 → 更新中断频率 = 84e6/(84*1000) = 1kHz */
TIM3->PSC  = 83;                 /* 84M/84 = 1MHz 计数节拍 */
TIM3->ARR  = 999;                /* PWM 频率 = Tclk/(PSC+1)/(ARR+1) = 1kHz */
TIM3->CCR1 = 250;                /* 占空比 = CCR/(ARR+1) = 25% */
TIM3->CCMR1 |= 6<<4;             /* OC1M=110 PWM模式1：CNT<CCR 输出有效电平 */
TIM3->CCER |= 1<<0;              /* 使能 CH1 输出 */
TIM3->CR1  |= 1;                 /* 启动 */
```
分辨率权衡公式：`分辨率位数 = log2(Tclk/fpwm)`——频率越高 ARR 越小、可用位数越少。
> [!warning]- PWM 调光闪烁之谜
> 频率低于人眼临界值(<100Hz)或落在相机快门频段就会「闪」。LED 呼吸灯建议 ≥1kHz；风扇在低频段会因线圈振动啸叫，解法是提到 20kHz 以上。

## 25.3 原理深挖：预装载寄存器与影子寄存器
为什么有时改 CCR 立即生效，有时要等下个周期？CCR/ARR 有「预装载」影子机制：
```c
/* ARPE=1 → 你写的是预装载寄存器，更新事件(UEV)才同步进影子寄存器(真正参与比较的那个)
   ARPE=0 → 写入直达影子 → 立即生效但可能产生畸形脉冲！
   PWM 相位连续性要求 → 标准姿势：ARPE=1 + 在周期首改参数 */
TIM3->CR1 |= TIM_CR1_ARPE;       /* 使能 ARR 预装载 */
/* 高级定时器 RCR：每 N 个溢出才发一次 UEV ——
   20kHz PWM 下把 ADC 注入采样降到每 2 个周期一次的官方手段 */
```

## 25.4 中心对齐 PWM 与死区计算
**中心对齐的价值**：计数器走三角波，PWM 脉冲居中对称——电机相电流采样窗口天然落在计数中心，纹波最小，FOC 必选。
**死区（Dead Time）计算**：DTG 位域编码，`DTG[7:5]=000 → DT = DTG[7:0] × TDTS`；以 168M/2 的节拍计步约 84ns 一档，设 1µs 死区即 DTG≈11。务必用示波器量两管波形验证，而非纸面自信。

## 25.5 关键代码：输入捕获测频率/占空比
```c
/* 方案A 双沿法：CH1捕上升沿记t1，CH2捕下降沿记t2，再回上升沿t3
   高电平=(t2-t1)，周期=(t3-t1)，占空比=高/周期 —— HAL回调里三步完成 */
void HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim){
    if(htim->Channel==HAL_TIM_ACTIVE_CHANNEL_1){ t1=HAL_TIM_ReadCapturedValue(htim,TIM_CHANNEL_1); }
    else if(htim->Channel==HAL_TIM_ACTIVE_CHANNEL_2){
        t2=HAL_TIM_ReadCapturedValue(htim,TIM_CHANNEL_2);
        uint32_t period=t1_prev<t2 ? t2-t1_prev : t2+(ARR+1)-t1_prev;  /* 处理计数器回卷！ */
    }
}
/* 方案B DMA批捕法(测抖动统计)：TI1FP1 每沿触发 DMA 搬 CCR 到数组，
   离线算 min/max/均值/直方图 —— 抓按键抖动波形分布的神器 */
```

## 25.6 关键代码：编码器接口与单脉冲 OPM
```c
/* AB相正交编码器 → TIM3 Encoder Mode TI12：硬件4倍频自动辨向 */
TIM_Encoder_InitTypeDef enc={.EncoderMode=TIM_ENCODERMODE_TI12,
    .IC1Polarity=TIM_ICPOLARITY_RISING,.IC1Filter=10,   /* 滤波消抖 */
    .IC2Polarity=TIM_ICPOLARITY_RISING,.IC2Filter=10};
HAL_TIM_Encoder_Init(&htim3,&enc); HAL_TIM_Encoder_Start(&htim3,TIM_CHANNEL_ALL);
int32_t pos=(int16_t)__HAL_TIM_GET_COUNTER(&htim3);     /* 16位定时器要处理回绕 */
pos+=overflow_count*65536;
/* 转速(rpm)=Δcount/(PPR*4*T采样)*60 ；32位的 TIM2 可免回绕烦恼 */
int16_t d=(int16_t)(now-last);          /* 巧用 int16 强转自然处理±32767回绕! */
```
单脉冲模式 OPM（One Pulse Mode）：触发一次输出一个受控宽度脉冲——超声波测距/相机快门的标准硬件方案，CPU 只管触发。

## 25.7 参数调试技巧
| 症状 | 测量手段 | 调什么 | 判据 |
|------|----------|--------|------|
| 频率差一倍 | 示波器测周期反推时钟 | 核对 APB ×2 规则 | 实测=公式值 |
| 捕获值偶尔巨大 | 逻辑分析仪抓边沿 | 回卷模运算或从模式复位归零法 | 连续测量无离群 |
| 编码器反向跳变 | 示波器看边沿质量 | 加大 ICFilter；屏蔽双绞布线 | 反向无虚假计数 |

## 25.9 排故速查表
| 现象 | 根因候选 | 定位路径 |
|------|----------|----------|
| PWM 频率差一倍 | APB 分频≠1 时定时器时钟翻倍规则被忽略 | RCC_GetClocksFreq 核实实际输入时钟 |
| 占空比调不动 | 只改 CCR 没开预装载，或 MOE 主输出没使能 | CCxE 与 BDTR.MOE 双开关检查；预装载保证同步更新无毛刺 |
| 捕获值偶尔巨大 | 计数器回卷未处理 | 按 25.5 公式做模运算；或从模式复位计数器归零法 |
| 编码器反向计数跳变 | AB相滤波不足受干扰 | 加大 ICFilter；示波器看边沿质量；屏蔽双绞布线 |
| 更新中断周期不稳 | Jitter 来自同优先级中断阻塞 | 提高该定时器抢占级；ISR 内只置标志 |

## 25.10 部署注意事项
1. 改 ARR/CCR 统一走 ARPE=1 预装载路径，杜绝运行中畸形脉冲。
2. 高级定时器驱动半桥前先实测死区波形，刹车输入必须接线验证。
3. 编码器线缆用屏蔽双绞，滤波值按现场干扰实调，不抄默认。
4. ETR 外部时钟可让高频事件计数不占 CPU，比 EXTI 中断数沿快两个数量级。

## 25.11 进阶话题
- **RCR 重复计数器**：降低更新事件率，20kHz PWM 下 ADC 注入采样降频的官方手段。
- **DMA 批捕联动**：捕获+DMA 组合见 [[ch26-DMA与Cache一致性]] 的循环缓冲套路。
- **开源定位**：SimpleFOC 的 timer 配置层；STM32CubeF4 TIM_ComplementarySignals 示例；AN4776 官方定时器百宝书必读。

> [!warning]- ❓ FAQ
> **Q1：改了 CCR 输出出现一个怪脉宽？** ARPE 未开，写入直达影子寄存器，当前周期立即被截断——开预装载即可。
> **Q2：编码器计数值为何要先强转 int16_t？** 16 位计数器过零回卷，强转利用补码回绕把差值自然变成带符号增量。
