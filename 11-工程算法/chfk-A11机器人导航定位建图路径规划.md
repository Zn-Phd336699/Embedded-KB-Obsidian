## A11.2 轮式里程计：差速运动学与不可避免的漂移

```c
/* 差速底盘正运动学(每个控制周期) */
float dL=(encL-LastL)*M_PER_TICK, dR=(encR-LastR)*M_PER_TICK;
float dc=(dL+dR)/2.0f, dth=(dR-dL)/WHEEL_BASE;
pose.x += dc*cosf(pose.th+dth/2);
pose.y += dc*sinf(pose.th+dth/2);
pose.th += dth;
```

漂移三大来源(地毯实测口径)：轮径误差 1%→距离漂移 1%；轮距误差→角度漂移随路程放大 ★主导项；打滑(急转/地毯绒毛)→非系统性只能靠外部参考纠正。结论：**里程计 30s 内可信，分钟级必须外部锚定——这是定位层存在的理由。** 对照实验法：同一底盘瓷砖面 vs 地毯面各跑一次，分离「系统误差(可标定)」与「打滑噪声(需锚定)」。数值例题——轮距误差放大：标称轮距 W=200mm 实际 +1%，走边长 5m 正方形回起点；每个 90° 转弯角度误差 ε≈1%×π/2≈0.9°，四角累计 ~3.6°，横向偏差随已走角度旋转累积，走 20m 后横向偏移 ~35cm——必须外部锚定的定量理由。

## A11.3 关键代码：AMCL 自适应蒙特卡洛定位三步循环

用 N 个带权粒子表示「我可能在哪」的概率分布：

```c
/* 粒子结构 {x,y,θ,w} × N */
void amcl_step(particle_t*p,int n,const odom_delta_t*odom,const laser_scan_t*scan){
    for(int i=0;i<n;i++) move_particle(&p[i],odom);            /* ① 预测+高斯扰动 */
    for(int i=0;i<n;i++) p[i].w*=scan_match_score(&p[i],scan); /* ② 距离场查表打分 */
    normalize_weights(p,n);
    float Neff=1.0f/sum_of_squares(p,n);                       /* 有效粒子数 */
    if(Neff<n/2) systematic_resample(p,n);                     /* ③ 权重高复制低淘汰 */
}
```

工程参数手感：N=500~2000(M4F 跑 300 粒子实时可行)；注入少量随机粒子防「绑架问题」；收敛判据=粒子云方差阈值；三大参数(N/运动噪声σ/匹配宽度)全部由绑架测试标定。Neff 过低说明粒子退化(权重集中于极少数)。ROS amcl 包跑在 A 核；MCU 上做简化版是扫地机厂商的真实做法。

## A11.4 栅格地图占据更新（log-odds）与内存预算

每格存对数几率 l=ln(p/(1−p))，激光逐束更新：光束击中末端格 l+=l_occ(+0.85 典型,p≈0.7)；穿过空闲格 l−=l_free(−0.40 典型,p≈0.4)；读取 p=1−1/(1+eˬ)，p>0.65 判占据(典型值)；夹紧 \|l\|≤l_max 防单次观测过度自信。动态临时障碍只进局部代价层不写长期地图——防满屋「幽灵墙」。M4F 192KB RAM 结论：全屋距离场已超限 → 分区加载/降分辨率/M7 外挂 SDRAM 三选一。

| 地图规格 | 分辨率 | 格式 | 内存 |
|----------|--------|------|------|
| 单间 8×8m | 5cm | uint8 占据栅格 | 160×160=25KB |
| 全屋 15×15m | 5cm | +int16 距离场 | 300×300×3=270KB |
| AMCL 粒子 500 个 | - | 4×float | 8KB |

## A11.5 A\* 启发式搜索与 Dijkstra 对比

f(n)=g(n)+h(n)：已走代价+启发函数(到终点直线距离)。h 满足 admissible 不高估⇒结果最优——**第一次取出 G 时即为最优，不需要搜完全图**。Dijkstra 是 h≡0 特例：保证最优但盲目等向展开；A\* 靠 h 定向搜索展开数量级更少；h 若高估则更快但失去最优性。实现要点：二叉堆 openlist+closedset 栅格数组；分辨率=机器人半径×2 倍数并先做障碍膨胀(inflation)层；8 邻域对角代价 ×√2 且禁止「贴双墙穿角」；后处理 greedy 拉直(string pulling)去锯齿。复杂度：100×100 栅格毫秒级(F407)；更大地图上跳点搜索(JPS)提效。

## A11.6 DWA 局部避让直觉与调参

| 要素 | 说明 |
|------|------|
| 速度空间采样+前向仿真 | 当前 (v,ω) 可达范围按步长采样,每组推演 1~2s 轨迹 |
| 评分函数 | heading(贴全局路径)+dist(离障远)+velocity(快) 三加权 |
| 调参手感 | heading 大→死板贴线;dist 大→绕远胆小;sim_time 过长反应迟钝。起点 (0.8,0.4,0.1), sim=1.5s |
| 落地指标 | 20Hz 重规划；评分全定点化 M4 实测 <1ms/次 |

## A11.7 参数调试技巧

| 症状 | 测量手段 | 调什么 | 判据 |

| 走直线越来越歪 | 地面画实际轨迹对比 | 轮径/轮距标定+外部锚定 | 20m 横向偏差远小于 35cm 基线 |

## A11.9 排故速查表

| 现象 | 根因候选 | 定位路径 |
|------|----------|----------|
| 定位突然全丢(绑架) | 玻璃/镜面反射致激光失配 | 注入随机粒子进入重定位模式 |
| 满屋幽灵墙越积越多 | 动态障碍写入长期地图 | 只进局部代价层+定期衰减 |

## A11.10 部署注意事项

1. **频率匹配缓冲**：定位低频输出(LDS 5~10Hz)与控制高频需求(50Hz)间加轨迹外推层；
2. **粒子滤波确定性**：固定随机种子便于回归复现；量产版可用固定粒子模板降低抖动；
3. **动态障碍记忆策略**：临时障碍只进局部代价层不写长期地图；
4. **失效降级链产品化**：定位丢失→减速→沿墙模式→原地重建——各级触发阈值与用户提示明确定义。

## A11.11 进阶话题

- **VSLAM 与激光之争**：视觉便宜但算力/光照敏感；LDS 稳定但成本高——消费产品常见融合(激光为主、视觉补盲)；
- **ROS2 与 MCU 分工趋势**：micro-ros 让 M 核承担实时驱动层，A 核跑 Nav2 导航栈(P5 架构思想再现)；
- **TF 坐标树意识**：map→odom→base_link 三级变换链显式维护；A\* 锯齿折线经平滑/贝塞尔重拟合再交 DWA(平滑度与离障距离是权衡对)。

> [!warning]- ❓ FAQ
> **Q1：里程计为什么分钟级就不可信？**
> 轮距误差的角度漂移随路程放大+打滑非系统性——20m 横向偏移可达 ~35cm 量级。
> **Q2：Neff 有效粒子数过低说明什么？**
> 粒子退化(权重集中极少数粒子)触发重采样；频繁过低应检查运动噪声 σ 与匹配宽度。
