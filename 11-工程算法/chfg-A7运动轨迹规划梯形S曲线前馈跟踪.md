## A7.1 梯形速度曲线：三段规划与在线递推

三段式：加速(+amax 至 vmax) → 匀速巡航 → 减速(−amax 至 0)。在线版每周期只回答一个问题：「现在踩油门还是踩刹车？」——判据本体是减速距离 `d_dec = v²/(2a)`。

```c
/* 离散在线版：每控制周期走一步，无需预计算整条曲线 */
typedef struct { float pos,vel,acc; float vmax,amax; int32_t target; } trap_t;
void trap_step(trap_t *t){
    float d_rem = t->target - t->pos;
    float d_dec = t->vel*t->vel/(2*t->amax);          /* 刹车距离 v²/2a */
    if(d_rem <= d_dec && t->vel > 0)  t->acc = -t->amax;  /* 必须减速 */
    else if(t->vel < t->vmax)         t->acc = +t->amax;  /* 还可加速 */
    else                              t->acc = 0;         /* 匀速巡航 */
    t->vel = clamp(t->vel + t->acc*TS, 0, t->vmax);
    t->pos += t->vel*TS;
    if((d_rem<=0 && t->vel>=0) || (t->vel==0 && fabsf(d_rem)<1)){
        t->pos = t->target; t->vel = 0;               /* 收敛兜底 */
    }
}
/* 三种边界情况必须单测：
① 目标太近(没到 vmax 就要减速) → 自动退化为三角形 ★高频漏测
② 中途反向新目标 → 以当前 p/v/a 为初值重算，禁止跳变
③ 减速段到达但速度未归零 → 位置钳位+速度归零兜底 */
```

**多点连续路径衔接**：新目标到来时以上述结构体当前的 p/v/a 为初值重入规划——保留当前 acc 连续衔接，机构才不会「顿挫」。漏测边界①②是新规划器翻车率最高的两个用例，务必写进单元测试清单。

## A7.2 七段式 S 曲线：jerk 受限推导

梯形的两个拐角=加速度阶跃=激发机构振动的物理来源。七段式用 jerk（加加速度，m/s³）约束让加速度连续变化：①加加速(+j) ②匀加速 ③减加速(−j) ④匀速 ⑤⑥⑦对称减速——高频激励最小，精密机构零振动到位。

时间公式（「能否达 vmax」先行判定）：

```text
d_v = v·(v/a + a/j)              # 走完完整加减速的最短距离
若 d ≥ d_v：完整七段
  T1=T3=T5=T7=t_j=a/j ； T2=T6=v/a − a/j ； T4=(d−d_v)/v
若 d ＜ d_v：达不到 vmax → 退化为三角形 S 曲线，
  由 d 反解峰值速度 vp=f(d,a,j)(三次方程，数值解或查预生成表)
```

手把手数值例题：d=0.3m，vmax=0.8m/s，amax=2m/s²。粗判 `v²/(2a)=0.16m＜0.3m` 似可达 vmax；细算加速+减速共 0.32m＞0.3m → 匀速段 −0.02m＜0 矛盾！实际达不到 vmax，重解三角形 `vp=√(d·a)=0.775m/s`，t_total=2·vp/a=0.775s——**判定式先行避免了负匀速段的荒谬结果**。若 d=0.5m：s_c=0.18m，t_c=0.225s，总时 1.025s。

## A7.3 jerk 选取经验式：机械刚性 vs 响应速度

- j 越大越接近梯形（快/抖）；j 越小越柔（慢/稳）——本质是机构刚性与响应速度的折中；
- 经验式：`j ≈ amax / t_rise`，t_rise 取机构一阶固有频率周期的 1/4~1/3。例：皮带机构固有频率 15Hz → t_rise≈20ms → j=a/0.02（即 20ms 内建满加速度）；
- 实现两路：①在线递推 `acc += j·TS`(限幅 amax)、`vel += acc·TS`(限幅 vmax)，jerk 由「到 vmax/amax 的剩余时间」动态决定——约 40 行状态机；②查表法：预生成归一化 S 表（Q15，256 点），运行期按 vmax/amax 缩放——M0 上零浮点，缺点是中途改目标需重映射。

## A7.4 速度+加速度双前馈跟踪结构

轨迹发生器每周期输出三件套 `pos_ref, vel_ref, acc_ref`，前馈律：

```text
u_ff = Kv*vel_ref + Ka*acc_ref   (Kv=速度常数 V/(单位/s)；Ka=惯量系数 V/(单位/s²))
PID 仅处理残差 e = pos_ref − pos_meas
```

跟随误差分析（42 步进+S 曲线实测口径）：纯 PID 跟踪误差峰值 38 步 → 加双前馈后 4 步（↓90%）。原理：恒速/恒加速段的系统性需求被前馈**提前供给**，PID 只兜模型残差与扰动。

辨识 Kv/Ka：恒速段 `Kv=u/vel`；恒加速段 `Ka=(u−Kv·vel)/acc`，各采十点平均。工程细节：前馈通道同样过输出限幅；vel_ref 用滤波后值防微分噪声——「前馈为主、反馈兜底」正是 A5.1 配方在运动控制的落地。

## A7.5 实测数据表：三种规划在直线模组上的表现（42 步进+16 细分）

| 规划方式 | 300mm 定位时间 | 到位过冲 | 高速丢步率 |
|----------|----------------|----------|------------|
| 直接全速启停 | 0.41s | ＞5mm 震荡 | 12% |
| 梯形 | 0.52s | ＜0.3mm | ＜0.1% |
| S 曲线(j=20ms)+前馈 | 0.58s | ＜0.05mm | 0 |

结论：S 曲线比梯形慢约 10%，换来「无激励振动」——精密场景唯一解。

## A7.6 参数调试技巧

| 症状 | 测量手段 | 调什么 | 判据 |
|------|----------|--------|------|
| 到位过冲/机构异响 | 听音/加速度计 | 减小 jerk 或 amax | 过冲＜0.05mm(典型值) |
| 定位时间过长 | 抓 pos_ref 曲线 | 提高 vmax/amax/j | 不丢步不报警的上限 |
| 跟随误差大 | 记录 e=pos_ref−pos | 重标定 Kv/Ka | 残差降至前馈前约 10% |
| 终点蠕动不收敛 | 看末端速度曲线 | 终点积分/小脉冲敲击 | 快速收敛 ±1 计数 |

## A7.7 排故速查表

| 现象 | 根因候选 | 定位路径 |
|------|----------|----------|
| 减速段末端爬行很久才到位 | 低速摩擦死区+纯位置环 P 太小 | 加积分或终点小脉冲敲击(步进常用) |
| S 曲线中段超速报警 | jerk 段与匀速段时间重叠计算错 | 七段时间公式按「能否达 vmax」分支核对 |
| 改目标瞬间机构「顿挫」 | 重规划未从当前 acc 连续衔接 | 保留当前 acc 作新轨迹初值(A7.1 结构天然支持) |
| 高细分高速静默丢步 | 脉冲频率超定时器/光耦上限 | 核对细分数×最高转速×200 步/圈 ≤ 上限 |

## A7.8 部署注意事项（上线前五查）

1. **vmax/amax 出厂标定**：不同负载惯量下的可用 amax 差 3 倍以上——按负载型谱存参数组；
2. **脉冲频率上限核对**：细分数×最高转速×200 步/圈 ≤ 定时器/驱动器光耦上限——超频静默丢步；
3. **Ts 一致性**：规划步进与执行环同拍；jerk 段在低 Ts 下才平滑——Ts 过大时 S 曲线退化为梯形；
4. **急停/限位路径独立**：急停不经规划器直达封波/EN 断开；硬件限位触发后不走优雅减速而是立即最大减速停车（安全优先于平滑）；软限位则在规划器入口拒绝越界目标并告警；
5. **长时间运行漂移审计**：连续 1000 次往返累计位置误差统计——整数步数计数的实现应为零漂移（浮点累积位置是常见错误）。

## A7.9 进阶话题

- **多轴同步**：电子齿轮主从跟随 vs 各轴同 S 曲线时间对齐——后者保证路径形状，是联动插补的基础思想；
- **动力学前馈(MPC 级)**：已知质量/摩擦模型时可解析计算力矩前馈——A5 MPC 概念的最简落地形态；
- **步进对接三式**：PULSE/DIR（ARR 更新必须与更新事件同步/预装载，否则畸形脉冲丢步）、步数预算制（DMA+主从定时器成串产生，CPU 占用最低，适合高频细分）、闭环步进 TMC（直写目标位置寄存器，芯片内部闭环）；
- **回零(homing)状态化**：找限位→退避→慢速逼近→设零做成独立 FSM；断电位置存 NoInit/NVS，上电恢复基准免每次回零。

> [!warning]- ❓ FAQ
> **Q1：S 曲线比梯形多花多少时间？换来什么？** 典型值约 10%（0.52s→0.58s）；换来加速度连续、不激励机构振动，过冲从＜0.3mm 降至＜0.05mm、丢步清零。
> **Q2：为什么「能否达 vmax」判定必须先于一切计算？** 否则会解出负匀速段时间等荒谬结果；先分支再套公式是所有规划器代码的第一道闸。
