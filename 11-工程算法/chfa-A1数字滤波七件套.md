# 第A1章 数字滤波七件套
> [!info] 导航
> ⏱ 45min | ★★★☆☆ | 前置 [[chf0-A0算法篇导学与前置知识]] | → [[chfb-A2卡尔曼滤波族谱KF-EKF-UKF]]

## 🎯 学习目标
- [ ] 按噪声特征(白噪/脉冲/工频/漂移)选择滤波组合并排出级联顺序
- [ ] 写出七件套各自的差分方程与 C 实现，报出计算量与内存账单
- [ ] 完成 α/τ/f_c 换算并心算 RC 在 f_c 处 −3dB/−45° 的幅相代价

## A1.1 选型方法论：先问三个问题
- **① 噪声长什么样？** 采 2048 点画直方图+FFT：高斯白噪？偶发尖刺？50Hz 工频？缓慢温漂？——对症下药的前提是诊断；
- **② 能容忍多大延迟？** 所有平滑都以延迟为代价；控制环内滤波延迟直接吃相位裕度（A4 展开）；
- **③ 算力预算多少？** M0 上连除法都要省——乘加型滤波器优先。

## A1.2 七件套总览：差分方程核心与性格
| 滤波器 | 公式核心 | 治什么 | 副作用 | 单次开销(M4) |
|--------|---------|--------|--------|--------------|
| 滑动平均 MA(N)【FIR】 | y=Σx/N | 白噪 σ↓√N 倍 | 延迟 (N−1)/2 拍；阶跃爬坡慢 | O(1) 环形和 ~15cy |
| 加权滑动 WMA【FIR】 | 近重远轻加权和 | MA 的延迟减半版 | 平滑仍不足 | O(N) 乘加 |
| 中值 Median(N)【非线性】 | 窗口排序取中 | **脉冲尖刺克星** | 白噪抑制弱于 MA | 小 N 插入法 ~12cy(3点) |
| 限幅滤波 | \|x−y_prev\|>Δ 判野点丢弃 | 偶发野点兜底 | 真实跳变被误杀需调 Δ | ~8cy |
| 一阶滞后 RC(IIR 一阶) | y += α(x−y) | 高频白噪，延迟最小化 | 阶跃拖尾(63%@1τ) | ~10cy ★性价比王 |
| 峰值保持 Peak-hold | 窗口内 max 包络+衰减释放 | 瞬态峰值(电流浪涌) | 不降噪只包络 | ~10cy |
| 陷波 Notch(二阶 IIR Biquad) | 双零点对 ±ω0 | 工频及谐波 | 凹陷附近相位畸变 | ~20cy |

## A1.3 关键参数换算与频响要点（RC 与 MA）
```text
连续原型 tau·dy/dt + y = x ；前向欧拉离散：alpha = Ts/(tau+Ts) = 1/(1+2pi·fc·Ts)
三参数知一推二：fc = 1/(2pi·tau)；口诀——alpha 越接近 1 越「信新数据」
例① fc=10Hz、Ts=1ms ⇒ alpha≈0.941 ；例② tau=100ms ⇒ alpha≈0.0099
Q15 化：alpha_q15=alpha×32768；手算(α=.25,y0=100,x=200)：y1=125→y2=143.75→y3=157.8，
每拍剩余差距 ×0.75，收敛 ±5 内需 n≈10.4 拍
── MA 频响 H(f)=sin(pi·f·N/fs)/(N·sin(pi·f/fs))，sinc 形状 ──
直流增益 1；f=k·fs/N 处增益恰为 0 ——完全抑制！实例 fs=600,N=12 ⇒ 工频精确归零，
即「采样率锁工频整倍数」的数学原理；通带轻纹波、过渡平缓，陡峭需求上 Biquad 陷波
```

## A1.4 相位延迟对比表
| 滤波器 | 相位/延迟特征 | 控制环使用提示 |
|--------|---------------|----------------|
| 一阶 RC | f_c 处相移 −45°，高频趋近 −90° | 带宽规划必须计入这段「免费延迟」 |
| MA(N) | f=f_s/(2N) 处 −90°；等效纯延迟 (N−1)/2 拍 | 大 N 禁止放进闭环 |
| 中值 | 非线性相位；阶跃响应延迟约 1 拍 | 适合开环采集链 |
| 陷波 Biquad | 远离 ω0 相位小，凹陷附近剧烈畸变 | 只对准干扰频率使用 |

级联铁律：野点处理永远在平滑之前（否则尖刺被摊成宽包络）；每级留观测点可二分定位；相位预算超支优先删「非必需级」。

## A1.5 关键代码：统一接口 C 实现
```c
/* 1) O(1) 滑动平均：环形和增量更新，替代 O(N) 全量重加 */
typedef struct { int32_t sum; uint16_t buf[64]; uint8_t idx, n; } ma_t;
void ma_init(ma_t *f, uint8_t n){ memset(f, 0, sizeof(*f)); f->n = n; }
int16_t ma_run(ma_t *f, int16_t x){
    f->sum -= f->buf[f->idx];              /* 减最老 */
    f->sum += (f->buf[f->idx] = x);        /* 加最新 */
    if(++f->idx >= f->n) f->idx = 0;
    return (int16_t)(f->sum / f->n);
}
int16_t med3(int16_t a, int16_t b, int16_t c){ /* 2) 三点中值：比较网络无排序 */
    if(a > b){ if(b > c) return b; return a > c ? c : a; }
    return c > b ? b : (a > c ? a : c);
}
int16_t rc_run(int16_t y, int16_t x, int16_t alpha_q15){ /* 3) Q15: int32 中转防溢出 */
    return y + (int16_t)(((int32_t)alpha_q15 * (x - y)) >> 15);
}
/* 4) 50Hz 陷波 Biquad；fs=1kHz,r=.95 ⇒ b=[1,-1.902,1] a=[1,-1.807,.9025]，r 越近 1 凹陷越窄越深 */
typedef struct { float b0,b1,b2,a1,a2,x1,x2,y1,y2; } bq_t;
bq_t *notch_init(bq_t *f, float f0, float fs, float r){
    float cw = cosf(6.2832f * f0 / fs);
    *f = (bq_t){ 1, -2*cw, 1, -2*r*cw, r*r, 0, 0, 0, 0 };  return f;
}
float notch_run(bq_t *f, float x){
    float y = f->b0*x + f->b1*f->x1 + f->b2*f->x2 - f->a1*f->y1 - f->a2*f->y2;
    f->x2 = f->x1; f->x1 = x; f->y2 = f->y1; f->y1 = y;  return y;
}
/* 5) 组合拳黄金三段：clamp(raw) -> med3 -> rc_run —— 野点/脉冲/白噪各司其职 */
```

## A1.6 参数调试技巧：给滤波器做体检
| 症状 | 测量手段 | 调什么 | 判据 |
|------|----------|--------|------|
| σ 残余噪声超标 | 静态采 2048 点算 σ_in vs σ_out | N↑ 或 τ↑ | MA16 应 ≈ σ_in/4 |
| 阶跃跟随太慢 | 电位器快拧录 y[k] 序列 | α↑ / τ↓ | 63%@τ±10%，无过冲 |
| 野点穿透输出 | 注入 5 个 ±500 尖峰统计偏移 | 限幅/中值级前移 | 中值链 <2LSB 穿透 |
| 50Hz 残留 | 函数发生器 50Hz 定频注入 | fs 锁 600Hz 或 r↑ | 凹陷点=fs/N±2%，输出 <−30dB |

## A1.7 实测数据表：同一含噪信号下的表现（电位器+注入干扰）
| 滤波配置 | σ 残余噪声(LSB) | 阶跃 10-90% 延迟 | 野点穿透率 |
|----------|-----------------|------------------|------------|
| 无滤波 | 8.2 | - | 100% |
| MA16 | 2.0 | 7.5×Ts | 100%(摊平变宽) |
| RC(τ=8Ts) | 2.3 | ~12×Ts | 100% |
| 中值5 | 6.9 | 2×Ts | **<1%(≤2 点脉冲)** |
| 限幅+中值3+RC ★推荐链 | 2.4 | ~14×Ts | <0.5% |

工频现场在推荐链后再加一级 50Hz 陷波：σ 可降到 1.1 LSB，代价是额外 +3×Ts 延迟。

## A1.8 排故速查表
| 现象 | 根因候选 | 定位路径 |
|------|----------|----------|
| 滤波后反而更抖 | N 太大致 sum int32 溢出 | sum 升 int64 或分段归一化 |
| 50Hz 干扰滤不净 | 采样窗非整数个工频周期 | fs 锁 50 整数倍或上陷波器 |
| 控制环震荡加剧 | 环内滤波延迟吃相位裕度 | 滤波移出到显示支路，或降 τ 补 PD |
| 输出偶尔归零缓慢重爬 | 滤波状态放栈上局部变量每调用复位 | static 或上下文结构体指针传入 |
| 真实阶跃被滤没 | 限幅 Δ<阶跃幅度 或 τ 过大 | Δ 自适应(连续超限 K 次放行)、τ 重算 |

## A1.9 部署注意事项
1. **初始化预热**：上电首拍用首个样本填满历史(y=x₀)，否则从 0 爬升会被业务误判故障；
2. **ISR 上下文约束**：ISR 只入环形缓冲，中值排序等滤波放任务侧；
3. **定点饱和审计**：int16 输入 ×Q15 必须 int32 中转；α 按固定 Ts 推导，调用周期漂移会等效漂移 f_c；
4. **多实例隔离**：多通道共用结构时每通道独立状态实例——共享状态串扰是最隐蔽的 Bug 源。

## A1.10 进阶话题
- 自适应一阶滤波：误差大用大 α(快跟)、稳态用小 α(平滑)——一行增益调度；
- CIC 抽取滤波：Σ-Δ ADC 后的抽取级，纯加减法实现的高分辨率低速采集标准前级；
- WMA/峰值保持补充件与 CMSIS-DSP biquad 函数族；大窗中值的直方图法 O(N+量程)；FFT 验证手段见 [[chfi-A9信号处理FFT-Goertzel-NTC-SOC融合]]。

> [!warning]- ❓ FAQ
> **Q1：Q15 乘法忘右移会怎样？** 输出瞬间飞到饱和；正确写法 `((int32_t)alpha_q15*(x-y))>>15`。
> **Q2：中值窗口里用 qsort 为什么不行？** N=64 约 1100cy；小窗用插入/比较网络，大窗用直方图法。
