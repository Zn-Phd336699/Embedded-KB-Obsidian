## A3.1 核心概念：两种传感器的互补性
姿态解算的本质是让「快但漂移」的陀螺仪(gyroscope)与「稳但抖动」的加速度计扬长避短；注意加计测的是**比力**(specific force)而非加速度——静止水平时 az≈+1g：

| 来源 | 短时行为 | 长时行为 | 角色 |
|------|----------|----------|------|
| 陀螺仪(积分得角) | 快、平滑 | **漂移(零偏×时间)** | 高频信任源 |
| 加速度计(重力方向) | 运动加速度污染、抖动大 | 长期指向真水平(无累积误差) | 低频锚点 |
| 磁力计(可选) | - | 提供航向 yaw 锚点 | 第三轴校准 |

## A3.2 四元数基础与互补滤波
欧拉角的致命伤是万向锁(Gimbal Lock)：pitch=±90° 时 roll 轴与 yaw 轴空间重合、丢一个自由度，微小扰动引起 roll/yaw 疯狂互换。四元数 q=[cos(θ/2), sin(θ/2)·n̂] 是「旋转轴 n̂+转角 θ」的紧凑编码，四大红利：① 无奇异点；② 组合两次旋转=一次四元数乘法(仅 16 次乘法)；③ 归一化只需除以模长，数值稳定；④ 与旋转矩阵互转有固定标准公式。**工程纪律：内部永远用四元数传递，仅在输出层转欧拉角给人看。**姿态推进依赖微分方程 dq/dt = ½·q⊗ω（右乘机体系角速度纯四元数）：

```c
void quat_integrate(float *q,float gx,float gy,float gz,float dt){
    float dq[4]={ -0.5f*(q[1]*gx+q[2]*gy+q[3]*gz),
                   0.5f*(q[0]*gx+q[2]*gz-q[3]*gy),
                   0.5f*(q[0]*gy-q[1]*gz+q[3]*gx),
                   0.5f*(q[0]*gz+q[1]*gy-q[2]*gx)};
    for(int i=0;i<4;i++) q[i]+=dq[i]*dt;
    float n=1.0f/sqrtf(q[0]*q[0]+q[1]*q[1]+q[2]*q[2]+q[3]*q[3]);
    for(int i=0;i<4;i++) q[i]*=n;   /* 归一化必须！防模长发散 */
}
```

```c
roll  = atan2f(ay, az);                    /* 静止时绕 X 轴倾角 */
pitch = atan2f(-ax, sqrtf(ay*ay+az*az));   /* 例 ax=-0.26,az=0.97 → pitch≈14.9° */
/* yaw 加计无感——只能靠磁力计/陀螺积分！ */
/* 互补滤波：频域视角 高通(陀螺)+低通(加计)=全频段最优 */
float alpha = tau/(tau + dt);              /* tau=期望截止周期, dt=采样周期 */
angle = alpha*(angle + gyro*dt)            /* 快路：陀螺积分 */
      + (1-alpha)*acc_angle;               /* 慢路：加计算角拉回 */
/* dt=0.005s(200Hz)、时间常数约 1s → alpha≈0.995：α 大=信陀螺(动态好漂移慢修)，
   α 小=信加计(稳但抖)。可信度门控： ‖acc‖偏离 g 超 15%(机动污染)→本拍只走快路 */
```

## A3.3 Mahony 算法：完整推导与 C 实现
核心思想：用重力构造「测量 vs 预测」误差向量，PI 反馈同时修正四元数与陀螺零偏。误差叉乘 e=a_measured×a_predicted 的几何意义——**向量方向=把预测重力转到测量重力所需的旋转轴，模长∝夹角正弦=需修正角度大小**；相比互补滤波逐轴调参的标量比例，叉乘天然处理三维耦合，这是 Mahony 更优雅的根源。

```c
typedef struct {
    float q[4];      /* 姿态四元数 [w,x,y,z] */
    float kp, ki;    /* Kp 拉回力度 / Ki 零偏估计速度 */
    float ix,iy,iz;  /* 误差积分 = 陀螺零偏估计 */
} mahony_t;
void mahony_update(mahony_t *m,float gx,float gy,float gz,
                   float ax,float ay,float az,float dt){ /* 角速度 rad/s! */
    if(!ax && !ay && !az) return;
    float n=1.0f/sqrtf(ax*ax+ay*ay+az*az); ax*=n; ay*=n; az*=n; /*必须归一化*/
    float q0=m->q[0],q1=m->q[1],q2=m->q[2],q3=m->q[3];
    float vx=q1*q3-q0*q2, vy=q0*q1+q2*q3, vz=q0*q0-q1*q1-q2*q2+q3*q3; /*①预测重力*/
    float ex=ay*vz-az*vy, ey=az*vx-ax*vz, ez=ax*vy-ay*vx;             /*②误差叉乘*/
    m->ix+=m->ki*ex*dt;  m->iy+=m->ki*ey*dt;  m->iz+=m->ki*ez*dt;     /*③Ki学零偏*/
    quat_integrate(m->q, gx+m->kp*ex+m->ix,                           /*④Kp拽回*/
                         gy+m->kp*ey+m->iy,
                         gz+m->kp*ez+m->iz, dt);
}
```
调参口诀：Kp 决定「拉回力度」(0.5~5 常用，大=跟快但抖)；Ki 从 0 起步，仅当存在可观测恒定漂移时缓慢加(0.001 级)；振动平台先降 Kp 到不抖再靠 Ki 补精度。九轴扩展：磁场向量同样做一次叉乘并先投影水平面(剔除磁倾角、只修 yaw)，第三分量汇入 ez——架构不变只多一路观测。陀螺零偏上电 SOP：静止≥2s(振动环境均值+3σ 剔野值)→采 500 帧 gyro 取中位数存 NVS→运行期交由 Ki 通路持续微调补温漂→对比出厂基准突变超阈值即告警。

## A3.4 Madgwick：梯度下降一步法
每拍沿目标函数(测量方向与预测方向对齐)的负梯度修正四元数并归一化；β 是唯一旋钮，工程口径=测量噪声强度增益：β 大=信加计多、收敛快但抖：

| 步骤 | 操作 | 判据 |
|------|------|------|
| ① 起点值 | β=1.0(作者推荐起点)，β 大=收敛快但静态抖动大 | 折中起点 |
| ② 静态测试 | 静置 10min 看 roll/pitch 漂移曲线 | 漂移超 1°→β×1.5 重测 |
| ③ 动态测试 | 手持快速翻转 10 次 | 翻转中角度毛刺大→β÷1.5 |
| ④ 收敛判定 | 重复②③直到两者同时达标 | 通常 2~3 轮收敛于 0.3~3 区间 |

## A3.6 参数调试技巧（可视化驱动整定）
| 症状 | 测量手段 | 调什么 | 判据 |
|------|----------|--------|------|
| 静置段缓慢漂移 | 串口 50Hz 输出 roll/pitch，VOFA+/SerialPlot 实时绘图 | Ki 从 0 缓升 | 漂移斜率趋于 0 |
| 阶跃收敛慢或过冲多 | 手动 90° 翻转×10 看收敛时间与过冲 | 收敛慢→Kp↑；抖动→Kp↓ | 快速收敛且不振荡 |
| 振动耦合明显 | 装到小电机旁运行观察抖幅 | 启用可信度门控或降 α | 抖幅回落至静置水平 |
| 温变后零偏变大 | 自然温差连跑 30min 记录零偏曲线 | 存温补表或多点系数 | 全温区零偏受控 |

单位红线：dps÷57.2958=rad/s——设 ±2000dps 却按 rad/s 积分会差 57.3 倍，**最高频换算错误**。

## A3.7 排故速查表
| 现象 | 根因候选 | 定位路径 |
|------|----------|----------|
| yaw 缓慢旋转不停 | 无磁力计锚点+陀螺 z 轴漂移(正常物理现象) | 加磁力计，或应用层接受 yaw 开环 |
| roll/pitch 怠速抖动 | 发动机振动耦合进加计 | 可信度门控+加大 α；机械减振垫 |
| 快速翻转后恢复慢 | Kp 太小拉回无力/加计饱和削顶 | 增大 Kp 或动态 Kp(角速度大时提高) |
| 四元数模长发散 | 未归一化/数值误差累积 | 每步 normalize(q)；Q30 定点注意溢出 |

## A3.8 部署注意事项（上线前五查）
1. **安装方向一致性**：传感器系→机体系的方向矩阵唯一确定并文档化，「roll 反了」九成源于此；
2. **单位链路审计**：原始寄存器→量程→dps→rad/s 全链路打印一组数人工核对；
3. **上电静默期**：启动后前 2s 强制静置采零偏，期间业务不得读取姿态；
4. **温度策略**：零偏温漂显著(-40~85℃ 可达数 dps)——存温补系数或接受运行期 Ki 自适应；
5. **失效安全**：通信丢失/数据冻结检测(连续 N 帧相同即告警)，云台类必须有「姿态未知」降级模式。

## A3.9 进阶话题
- **磁力计硬铁+软铁校准**：立体 8 字翻滚≥2min 采≥2000 点；硬铁偏置=(max+min)/2；软铁椭球拟合求 3×3 校正矩阵；验证判据=校正后点云落在以原点为心、半径约 0.5 Gauss 的球面；换壳/换安装位即失效——产线逐台校准或引导用户八字校准；
- **常见错误自查**：dt 用固定宏但任务周期抖动±20%(改 DWT 实测)；未归一化就进 Mahony(Kp 效果随幅值漂移)；倒装沿用默认轴向致符号全反。

> [!warning]- ❓ FAQ
> **Q1：四元数微分为什么右乘 ω？左乘是什么？** 右乘对应机体系(body frame)角速度，左乘对应世界(导航)系表示，不可混用。
> **Q2：Madgwick 的 β 与 Mahony 的 Kp 如何对应？** 都是「信任测量、拉回姿态」的力度旋钮；β 单旋钮易调，Mahony 多一条 Ki 通路能在线学走零偏。
> **Q3：磁力计修正为何先投影水平面？** 剔除磁倾角影响、只修 yaw；不投影会把倾角误差灌进 roll/pitch。
