# A5章 复合与现代控制：前馈、串级、Smith 与 LQR

> [!info] 导航
> ⏱ 40min | ★★★★☆ | 前置 [[chfd-A4-PID工程化全集抗饱和自整定]] | → [[chff-A6电机控制数学内核Clarke-Park-SVPWM-SMO]]

单环 PID 调到顶之后，性能的下一级台阶来自「结构」：可测扰动用前馈（Feedforward），大惯性对象用串级（Cascade），大滞后用 Smith 预估器（Smith Predictor），多变量最优用 LQR（Linear Quadratic Regulator）。

## 🎯 学习目标
- [ ] 能为可测扰动设计前馈+反馈复合结构，并用开环辨识标定前馈系数
- [ ] 能按「先内环后外环」顺序整定串级系统并说明带宽分离原则
- [ ] 能写出 LQR 代价函数与 Riccati 方程，完成「PC 求解→MCU 点积」落地

## A5.1 前馈+反馈复合：把「已知」提前干掉

反馈只能**事后纠错**，可测扰动/设定变化可以**事前补偿**，二者分工明确：

```text
u = u_FF + u_FB     （前馈管「已知的快」，反馈兜「未知的残」）
```

- 案例① 云台：载体角速度 ω_base 可测 → 前馈项 `-ω_base×Kff` 直接抵消载体运动，PID 只处理残差——追踪延迟从 80ms 降到 12ms；
- 案例② 加热：设定值斜坡的导数作为功率前馈（能量守恒），PID 只补热损——跟踪误差降一个量级且 Kp 可以更小。

工程要点：前馈系数标定=开环辨识一次（阶跃响应斜率）；前馈通道同样加限幅+滤波，防止测量噪声直灌输出；「前馈为主、反馈兜底」是高精度系统的通用配方。

## A5.2 串级控制：三环套娃设计法（温控案例）

| 环 | 被控量 | 带宽设计 | 本案例参数 |
|------|----------|--------|------|
| 内环(电流) | SSR 电流 | ＞10× 中环 | P 控制，100Hz，几乎瞬时 |
| 中环(温度率) | 升温速率 | ~1Hz | PI，抑制加热膜不均扰动 |
| 外环(温度) | PT100 温度 | 0.1Hz | PI+Smith，负责最终精度 ±0.2℃ |

串级三条铁律：

1. **带宽分离**：内环必须显著快于外环（＞10×），否则外环指令在内环眼里是噪声；
2. **整定顺序**：每环独立整定，先内后外——内环闭合且稳定后再动外环；
3. **级联抗饱和**：内环饱和要向外环传信号（Anti-windup 级联），否则外环积分照样飞。

适用判据：被控对象存在「中间物理量既可测又能快速影响输出」才值得串级，否则单环+A5.1 前馈更简单可靠。

## A5.3 Smith 预估器：给大滞后装「时光机」

痛点：长管道温控等**纯滞后 τ 占主导**的对象，PID 看到 e 时已晚了 τ 秒，无论怎么整定都陷入「震荡-迟钝」二选一。

结构：用对象模型 `Gm(s)·e^(−τm·s)` 并联一条「无滞后虚拟反馈」——控制器实际调节的是预估的无滞后误差，真实滞后被移出反馈回路，PID 可放心加大增益。嵌入式离散实现：模型输出经 FIR 延迟线（长度 N=τ/Ts）得到 y_pred[k]，控制误差取 `set − y_meas 的延迟补偿项` 送入 PID。

模型失配是软肋：τ 或增益估偏 20% 以上效果骤降。对策：在线一阶+FOPDT 辨识（继电器法顺带出模型）定期刷新；残差持续偏大就退回普通 PID。

## A5.4 LQR：代价函数、Riccati 与一行点积 ★

```text
对象(云台单轴速度环二阶简化)： ẋ = Ax + Bu ,  x=[ω误差, i误差]
代价函数： J = ∫ (xᵀQx + uᵀRu) dt
最优解：   u = −Kx ,  K = R⁻¹BᵀP ；Riccati： AᵀP + PA − PBR⁻¹BᵀP + Q = 0
Q/R 直觉： Q 大=「偏差不可容忍」(激进压偏差)；R 大=「力气很贵」(平缓省电)
```

工程红利：**设计在 PC 完成，运行期成本≈零**——主机用 `scipy.linalg.solve_continuous_are` 解 P 得 K=R⁻¹BᵀP 并固化进固件常量表（例 K=[-6.32,-0.41]，校验 eig(A−BK) 实部全负）；MCU 只需一行点积，P 矩阵不上 MCU。

```c
/* 云台速度环 LQR(F407, 10kHz)：主机解 Riccati 后固化 K */
static const float K[2] = {-0.86f, -0.31f};
float lqr_speed(float w_err, float i_err){
    float u = -(K[0]*w_err + K[1]*i_err);   /* 状态反馈点积 */
    u += feedforward_from_gyro();           /* 叠加 A5.1 前馈 */
    return clamp(u, U_MIN, U_MAX);
}
/* 积分增强(LQI)：把 ∫e 并为第三状态重新解 K——稳态误差归零 */
```

手算一步：ω_err=15°/s、i_err=0.2A 时 `u=−((−6.32)×15+(−0.41)×0.2)=+94.9`＜U_MAX 不饱和；下一拍 ω_err 收敛到 5 → u 自动回落到 31.7——**增益固定而输出随状态自然收缩**。

## A5.5 参数调试技巧（Q/R 权衡）

| 调节动作 | 阶跃响应变化 | 代价表现 | 何时这么调 |
|------|----------|--------|------|
| q_ω ×10(状态权重↑) | 恢复时间 −40%，超调略增 | 电流噪声放大、发热↑ | 跟踪速度不达标时 |
| r ×10(控制权重↑) | 响应变缓变柔 | 省电降噪、机械冲击小 | 执行器发热/噪音超标时 |
| 交叉项 q_i ↑ | 电流更「听话」地跟随需求 | 对电流采样噪声敏感 | 需要精确转矩控制时 |

迭代流程：设初值(Q=I, R=1)→仿真/实测→按短板方向调→2~4 轮收敛，**每次只动一个旋钮**。

## A5.8 部署注意事项（上线前五查）

1. **模型有效性验证**：部署前用实测阶跃响应与模型仿真叠加对比——失配＞20% 先修模再上线；
2. **鲁棒性验证**：负载增减 ±50%、电源 ±10% 下重跑指标；「无限增益裕度/60° 相位裕度」的经典结论仅在全状态可测的理想假设下成立——输出反馈+未建模动态时必须实机做增益/相位裕度扫描与参数摄动实验；
3. **前馈通道防噪**：ω_base 必须先滤波再乘 Kff——噪声直灌输出是前馈系统的第一事故源；
4. **Smith 失配监控**：残差统计持续偏大=模型过期——触发在线辨识刷新或退回普通 PID；
5. **调度边界测试**：分界温度附近反复穿越时的稳定性专项测试。

## A5.9 进阶话题

- **离散 LQR 两步走**：对象按 Ts 离散化(c2d)→解 DARE(solve_discrete_are)；连续增益直接搬数字环会在高频段打折；
- **LQG 桥接**：LQR+Kalman 依分离定理独立设计再级联，但各自稳定≠整体最优裕度，实测验证不可省；
- **MPC 最小思想**：显式计算未来 N 步代价选当前最优 u、滚动优化——本质差异是显式处理约束与未来；正式实现需 QP 求解器，MCU 仅小规模可行（如 2×2、horizon≤10）。

> [!warning]- ❓ FAQ
> **Q1：为什么说 LQR 的计算发生在设计期而非运行期？** Riccati 方程只在 PC 解一次得到 K；固件里 K 是常量表，运行期只有 n 次乘加的点积，P 矩阵不出现在 MCU 上。
> **Q2：Smith 预估器取代 PID 吗？** 不。它改造的是反馈通路——把纯滞后移出回路后，内层仍是那个可以放心加大增益的 PID。
